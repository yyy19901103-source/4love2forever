## 01-1 離散数学：カルノー図（1日目 問1、令和7年度秋期 問1＝令和4年度秋期 問2と同一）

### 定義
1. **マス**：A・B・C・D の値の組1つ。行見出しが AB、列見出しが CD。例：AB=01・CD=10 のマスは (A,B,C,D)=(0,1,1,0)。
2. **隣接**：2つのマスの4ビットを比べ、値が違うビットがちょうど1つ。図の上の位置は関係ない。
   - (0,0,0,0) と (0,0,1,0)：C だけ違う → 隣接
   - (0,0,0,0) と (0,0,1,1)：C と D が違う → 隣接でない
   - 見出しを 00・01・11・10 の順に並べるのは、並んだ見出しどうしと、最後（10）と最初（00）を、すべて1ビット違いにするため。
3. **まとまり**：次の3条件をすべて満たすマスの集合。
   1. すべてのマスの値が1。
   2. 個数が 2^k 個（k＝0〜4、つまり1・2・4・8・16個）。
   3. k 個の変数が 0/1 のすべての組合せ（2^k 通り）をとり、残り 4−k 個の変数は全マスで同じ値。
4. **項**：まとまりの中で値が同じ変数だけを論理積でつなぐ。値1 は X、値0 は X̄。
5. **答えの式**：値1のマスがすべてどれかのまとまりに入るように選び、項を論理和でつなぐ。k をできるだけ大きく、そのうえでまとまりの数をできるだけ少なくする。

### 手順
1. 値1のマスを4ビットで書き出す。
2. k の大きいまとまり（8個→4個→2個→1個）から、定義3を満たすか判定する。
3. 項を論理和でつなぐ。

### 問1の結果
- {0101, 0111, 1101, 1111}：A と C が全組合せ、B=1・D=1 が共通 → B・D
- {0000, 0010}：C が全組合せ、A=0・B=0・D=0 が共通 → Ā・B̄・D̄
- 答え：Ā・B̄・D̄ ＋ B・D（エ）

### 選択肢を消す方法
値1のマスを1つ選び、各選択肢に代入する。結果が0になる選択肢は誤り。

## 01-2 応用数学：M/M/1 待ち行列（1日目 問2、令和7年度秋期 問2）

### 定義
- **利用率 ρ**：処理装置が動いている時間の割合（0〜1）。ρ＝平均到着率×平均処理時間。
- **平均待ち時間 W**：処理が始まるまで待つ時間の平均。処理中の時間は含まない。
- **平均応答時間 R**：待ち時間＋処理時間。

### 式
- W ＝ ρ／(1−ρ) × 平均処理時間
- R ＝ 平均処理時間／(1−ρ)　（＝ W ＋ 平均処理時間）

### 問2の結果
平均処理時間 T、条件は W ≧ T。
ρ／(1−ρ) × T ≧ T → ρ／(1−ρ) ≧ 1 → ρ ≧ 1−ρ → ρ ≧ 0.5 → 50%（イ）

### 注意
問題文が「待ち時間」と「応答時間」のどちらを聞いているかを、最初に確かめる。
