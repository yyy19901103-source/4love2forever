## 01-1 離散数学：カルノー図（1日目 問1、令和7年度秋期 問1＝令和4年度秋期 問2と同一）

### 定義
1. **マス**：表の中で数字（0か1）が1つ書いてある箱。4行×4列で16個。
2. **マスの名前**：行見出し AB の2ビット＋列見出し CD の2ビット＝4ビット（ABCD の順）。例：AB=11・CD=10 のマスは 1110（A=1, B=1, C=1, D=0）。
3. **値**：マスに書いてある数字（0か1）。
4. **1ビット違い**：2つのマスの名前を比べ、違うビットがちょうど1つ。図の上の位置は関係ない（00 と 10 の列も1ビット違い）。
5. **候補**：次の2条件を満たすマスの集合（値はまだ見ない）。
   1. 個数が 1・2・4・8・16 のどれか（2^k 個）。
   2. k 個の変数（消える変数）が 0/1 のすべての組合せをとり、残り 4−k 個の変数は全マスで同じ値。
6. **組**：候補のうち、中のマスの値が全部1のもの。
7. **マス X を含む候補（組）**：X が中のマスの1つになっている候補（組）。X を含む候補は、消す変数の選び方で決まり、全部で16通り（16個:1、8個:4、4個:6、2個:4、1個:1）。
8. **組の式**：組の中で全マス同じ値の変数だけを「・」でつなぐ。値1 は X、値0 は X̄。混ざる変数は書かない（消える）。

### 変数が消える理由
値1のマスは4文字の項で書ける（0010 → Ā・B̄・C・D̄）。図の式は値1のマスの項を全部 ＋ でつないだもの。
Ā・B̄・C̄・D̄ ＋ Ā・B̄・C・D̄ ＝ Ā・B̄・D̄・(C̄ ＋ C) ＝ Ā・B̄・D̄・1 ＝ Ā・B̄・D̄。
C̄ ＋ C ＝ 1 なので C が消える。C̄ の項と C の項の両方が必要なので、消える変数は全組合せがそろっていなければならない。4個の組はこの計算を2回、8個の組は3回行ったことになる。

### 手順
1. 値1のマスを、名前（4ビット）で全部書き出す。
2. 値1の各マスについて、「1ビット違いで値が1のマス」の数を数える。
3. まだ組に入っていないマスのうち、2の数が最も少ないマスを1つ選ぶ。同じ数が複数あれば、名前を2進数として最も小さいマスを選ぶ。
4. 選んだマス X を含む候補を、大きい順（16個→8個→4個→2個→1個）に調べる。
   - 候補の作り方：消す変数を選び、消さない変数は X と同じ値に固定し、消す変数に 0/1 のすべての組合せを入れる。
   - 中に値0のマスが1つでもあれば、その候補は組ではない。
   - 組が見つかった大きさで止める。同じ大きさの組が複数あれば、まだ組に入っていないマスを最も多く含む組を選ぶ。それも同じなら、ほかのマスの名前が最も小さい組を選ぶ。
   - すでに組に入ったマスを含んでよい。
5. 値1のマスがすべて組に入るまで、3〜4をくり返す。
6. 各組について、その組のマスが全部ほかの組に入っていれば、その組を消す。
7. 残った組の式を ＋ でつなぐ。
8. （試験）値1のマスを1つ選んで選択肢に代入し、0になる選択肢を消して確かめる。

### 注意
この手順で毎回の選択は1つに決まるが、ごく一部の図では最短の式にならないことがある。手順6と手順8で確かめる。

### 問1の結果
- {0101, 0111, 1101, 1111}：A と C が全組合せ、B=1・D=1 が共通 → B・D
- {0000, 0010}：C が全組合せ、A=0・B=0・D=0 が共通 → Ā・B̄・D̄
- 答え：Ā・B̄・D̄ ＋ B・D（エ）

### 選択肢を消す方法
値1のマスを1つ選び、各選択肢に代入する。結果が0になる選択肢は誤り。

## 01-2 応用数学：M/M/1 待ち行列（1日目 問2、令和7年度秋期 問2）

### 定義
- **利用率 ρ**：処理装置が動いている時間の割合（0〜1）。ρ＝平均到着率×平均処理時間。
- **平均待ち時間 W**：処理が始まるまで待つ時間の平均。処理中の時間は含まない。
- **平均応答時間 R**：待ち時間＋処理時間。

### 式
- W ＝ ρ／(1−ρ) × 平均処理時間
- R ＝ 平均処理時間／(1−ρ)　（＝ W ＋ 平均処理時間）

### 問2の結果
平均処理時間 T、条件は W ≧ T。
ρ／(1−ρ) × T ≧ T → ρ／(1−ρ) ≧ 1 → ρ ≧ 1−ρ → ρ ≧ 0.5 → 50%（イ）

### 注意
問題文が「待ち時間」と「応答時間」のどちらを聞いているかを、最初に確かめる。
