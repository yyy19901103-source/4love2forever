# シラバス照合レポート（AP 科目A）

`python scripts/syllabus.py check --out docs/syllabus_check.md` で生成。
照合元：data/syllabus_A.json（ユーザー提示。シラバス Ver.7.2 から抽出）。
照合方法：学習項目の名前・要点と、シラバス項目の名前・用語例の一致語を数える機械照合。同じ小分類で見つからなければ、全小分類から名前で探す。用語例は「例」なので、載っていない語が出題範囲外とは限らない。
